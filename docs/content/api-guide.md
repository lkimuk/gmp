# API Guide

This project publishes an English-only API reference generated by Doxygen.

## Browse the Reference

- [Open the generated API reference](https://lkimuk.github.io/gmp/api/)

## Local Generation

If Doxygen is installed, configure the project with `BUILD_DOCS=ON` and build the `docs` target:

```bash
cmake -B build-docs -DBUILD_DOCS=ON
cmake --build build-docs --target docs
```

The generated HTML is written to `static/api/reference/`.

## Deployment Model

- Hand-written guides are built by Docusaurus
- Doxygen output is generated into `static/api/reference/`
- GitHub Actions builds and deploys the complete site to GitHub Pages

## Language Policy

- Guides are maintained in English and Simplified Chinese
- The generated API reference is currently English-only
