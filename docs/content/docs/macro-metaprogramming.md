# Macro Metaprogramming

This section documents GMP macro facilities for token composition, boolean logic, tuple operations, loops, and overload dispatch.

## Highlights

- Boolean and arithmetic macro helpers
- Tuple traversal and expansion
- Repetition helpers such as `GMP_FOR_EACH`
- Lightweight compile-time code generation patterns
